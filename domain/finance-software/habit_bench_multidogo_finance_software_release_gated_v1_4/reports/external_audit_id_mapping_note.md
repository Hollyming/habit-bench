# External AUDIT ID mapping note

The adjudication feedback names eight Finance items as `AUDIT-*`, but the v1.3 release package does not contain an `AUDIT-* -> probe_id` mapping field or file. v1.4 therefore applies the requested 5/1/1/1 type profile through the packaged graph-reachability audit and replaces eight structurally equivalent failures recorded in `finance_scope_anchor_replacements.csv`.

For a future adjudication round, the external audit export should retain both `audit_id` and `probe_id` so corrections can be linked without reconstruction.
