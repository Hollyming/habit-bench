## 实验口径

- 数据：Food v5、Finance/Software v1.4、Travel v13。
- 方法与回答模型使用同一 Qwen3 规模；`Full-Memory` 是 query-independent online compact history + recent raw context。
- 表中所有比率均为百分数；`Pooled Acc` 按 probe 数量汇总，括号为 Wilson 95% CI；`Macro Acc` 为四域（或当前可用域）的等权平均。
- `ER` 对 Top-5 memory 方法表示 `Evidence Recall@5 (macro)`，对 Full-Memory 表示 `Context Evidence Recall (macro)`，二者检索预算不同，不应直接作同口径排名。
- LightMem/MIRIX 当前没有稳定的 source-session lineage；其证据类指标为 0 主要表示不可归因，而不等价于没有取回文本。
