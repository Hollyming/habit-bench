# HABIT-Bench 主实验当前结果

> 快照时间：2026-08-31（HKT）。当前正式口径统一使用 Food final、Finance/Software
> v1.4 和 Travel v16；旧 Food v5 与 Travel v13 只保留为 legacy，不进入当前汇报。

## 实验口径

- Food final：`domain/food/food_habit_lifelines_final_check`，30 users、3,900 sessions、
  630 probes。
- Finance/Software：`habit_bench_multidogo_finance_software_release_gated_v1_4` 的
  `finance`（1,368 probes）和 `software`（680 probes）域。
- Travel：`release_candidate_v16_postrepair_repaired_r4`，650 probes。
- 主方法与回答模型使用同一 Qwen3 规模；`Full-Memory` 是 query-independent online
  compact history + recent raw context。
- 跨域主表列出 9 个 lifecycle memory methods。Food final 另外包含 Recency-5/10、
  BM25-RAG、Dense-RAG 和 Temporal Hybrid-RAG 五个 session-level retrieval baseline，
  其 Food-only 的四个模型明细也合并在本文中。
- 表中比率均为百分数；`Pooled Acc` 按 probe 数量汇总并给出 Wilson 95% CI，`Macro Acc`
  为当前有效域等权平均。`ER` 对 Top-5 方法表示 Evidence Recall@5，对 Full-Memory
  表示 Context Evidence Recall，二者检索预算不同。
- LightMem/MIRIX 没有稳定 source-session lineage；其证据类指标为 0 主要表示不可归因，
  不等价于没有取回文本。

## Qwen3-8B 简单 session-retrieval 基线

这些方法以完整 session 为 retrieval unit，不进行 LLM 记忆抽取、摘要或 agentic
lifecycle。`Recency-k` 返回 cutoff 前最近的固定 session 数；BM25 是词法检索；
Dense-RAG 使用统一 BGE-M3；Temporal Hybrid-RAG 使用 BM25/BGE-M3 RRF 和
as-of-aware temporal prior。
