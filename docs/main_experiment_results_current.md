## 实验口径

- 数据：Food v5、Finance/Software v1.4、Travel v16（`release_candidate_v16_postrepair_repaired_r4`，650 probes）。Travel 已使用独立 v16 主实验结果替换旧四域目录中的 v13，本文不再汇报 v13 Travel。
- 方法与回答模型使用同一 Qwen3 规模；`Full-Memory` 是 query-independent online compact history + recent raw context。
- 表中所有比率均为百分数；`Pooled Acc` 按当前可用域的 probe 数量汇总，括号为 Wilson 95% CI；`Macro Acc` 为当前可用域等权平均。
- `ER` 对 Top-5 memory 方法表示 `Evidence Recall@5`，对 Full-Memory 表示 `Context Evidence Recall`，二者检索预算不同，不应直接作同口径排名。
- LightMem/MIRIX 当前没有稳定的 source-session lineage；其证据类指标为 0 主要表示不可归因，而不等价于没有取回文本。
- Qwen3-14B MIRIX 的 Travel v16 补跑已完成并通过 strict merge；Qwen3-32B Mem0 的 Finance/Software 仍不完整。
